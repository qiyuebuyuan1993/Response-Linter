# Response-Linter 回归测试

## 自动化回归

使用已安装的 Node.js 24，无需安装依赖：

```sh
node --test tests/*.mjs
```

若当前沙箱禁止 Node 测试运行器 `spawn` 子进程（EPERM），可在同一进程直接执行：

```sh
node tests/regression.mjs
node tests/features-1.4.6.mjs
node tests/features-1.4.7.mjs
node tests/features-1.4.8.mjs
node tests/features-1.4.10.mjs
```

## 浏览器纯引擎夹具

从仓库根目录启动静态 HTTP 服务，再打开 `/tests/harness.html`（不要用 `file://` 直接打开 ES 模块）。
该夹具只验证纯引擎转换，不需要酒馆环境，也不能替代真实扩展验收。

## 酒馆内验收建议

1. 启用扩展开关，只打开一个修复功能，对最新 AI 回复点击“修复最新回复”；确认预览/直接应用行为符合设置。
2. 应用后点“撤销”，确认消息文本、显示文本、当前候选和保存结果恢复；关闭自动修复后手动修复仍可用。
3. 在“回复修复方案”中新建/复制/编辑/删除自定义档案，确认没有单独的旧关键词输入框；旧内置档案可直接编辑。
4. 打开历法折叠区，切换到构画/当前聊天来源；切换聊天或修改构画历法后确认状态自动更新，不需要手动检测。
5. 选择四季预设或自定义 JSON，构造缺少时间结束标记的回复；预览应使用所选历法，取消不写入。
6. 在流式生成期间尝试手动/自动修复，确认等待完成提示且不写入。
7. 检查正文外结构块顺序/配对和未知内容保留；歧义或归属不明时应只警告。
8. 打开扩展抽屉的原生 inline-drawer 行和魔法棒图标与中文名称入口，确认两者打开同一个浮层；键盘 Enter/空格可打开，焦点可见，窄屏不横向溢出。
9. 在“高级 / 帮助”中恢复 Quick Reply 按钮；删除按钮后不会被自动重装，点击才恢复；确认按钮不发送消息、不生成回复。
10. 使用千千结时，确认 `extra.qianqianjie_floor`、`qqj_v3_recall_receipt`、`qianqianjieAutoHide`、
    `qianqianjie_memory_excluded`、`swipe_info.extra` 与 `chatMetadata.qianqianjie` 不被改写；撤销是文本快照，
    不负责回滚修复后由其它插件新写入的元数据。
11. 尝试导入 1.4.9 或更早的配置（可含 `rules`）：确认只导入结构/历法/档案，旧规则不会重新执行；
    打开“高级 / 帮助”确认可单独导出旧规则留档；再次加载/导入不会覆盖已有留档。
12. 使用自定义 `<正文>` 等标签时，需要自行在千千结/构画的共享正文包装设置中配置相同标签；本扩展不会修改那边设置。

自动化测试不能替代真实酒馆版本及其他扩展组合的兼容性验收。撤销历史为页面内存数据，刷新后清空。
本版本未在真实 TauriTavern 2.4.0 / Windows / Android 设备上做验收；自动化与仓库内浏览器夹具
只覆盖模拟宿主和可用视口，不能宣称真机通过。
