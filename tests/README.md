# Response-Linter 回归测试

## 自动化回归

使用 Node.js 22.15+（推荐 Node.js 24），无需安装依赖：

```sh
node --test tests/regression.mjs
```

测试运行真实生产模块，仅模拟酒馆上下文、消息保存和 DOM 渲染接口。
覆盖：自动修复关闭时的手动修复、规则内容项保存/重新启用、修复预览、确认/取消、
文本/显示/候选回复撤销、多步历史、保存与渲染失败回滚、切换聊天及编辑保护、统计重置、
重复标签和代码围栏、禁止未选择策略回退。

## 浏览器纯引擎夹具

从仓库根目录启动静态 HTTP 服务，再打开 /tests/harness.html（不要用 file:// 直接打开 ES 模块）。
夹具验证双换行、顺序错误和位置插入，不需要酒馆环境。

## 酒馆内验收

1. 启用扩展，关闭自动修复；对缺少结束标签的最新 AI 消息点击手动修复。
2. 点击撤销，确认显示文本、复制文本和刷新后文本都恢复。
3. 禁用一个必需内容项并保存；关闭再打开编辑器，确认条目仍在且保持关闭。重新启用后检测恢复。
4. 将默认行为改为预览，确认取消不改消息，应用后可撤销。
5. 开启自动修复后重复验证撤销；确认不会因插件自己的渲染事件立即重新修复。

自动化测试不能替代真实酒馆版本及其他扩展组合的兼容性验收。撤销历史为页面内存数据，刷新后清空。
