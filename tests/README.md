使用 Node.js 22.15+（推荐 Node.js 24），无需安装依赖：

```sh
node --test tests/*.mjs
```

若宿主的 Node 测试运行器因沙箱禁止子进程 `spawn`（EPERM），可直接在同一进程执行：

```sh
node tests/regression.mjs
node tests/features-1.4.6.mjs
```

## 酒馆内验收

1. 启用扩展，关闭自动修复；对缺少结束标签的最新 AI 消息点击手动修复。
2. 点击撤销，确认显示文本、复制文本和刷新后文本都恢复。
3. 禁用一个必需内容项并保存；关闭再打开编辑器，确认条目仍在且保持关闭。重新启用后检测恢复。
4. 将默认行为改为预览，确认取消不改消息，应用后可撤销。
5. 开启自动修复后重复验证撤销；确认不会因插件自己的渲染事件立即重新修复。
6. 清除所有规则，只开启“清理泄漏的推理块”，点击手动修复预览；确认推理块消失而 `<content>` 正文保留。
7. 在构画设置一个自定义历法，开启“修复 SDC / 正文边界”，构造缺少 SDC-end 的 AI 回复；预览中应使用构画历法推进时间，取消不写入。换聊天后再次修复，历法来源应随新聊天变化。
8. 选择四季 28 日预设，用 `1年冬28日 周日 23:50` 起始、推进 10 分钟，预览应出现 `2年春1日 周一 00:00`。
9. 粘贴非法自定义 JSON，确认提示错误且不覆盖之前有效配置；“检测历法”显示来源和月份。
10. 在流式生成过程中点击手动修复，应提示等待生成完成而不写入。

自动化测试不能替代真实酒馆版本及其他扩展组合的兼容性验收。撤销历史为页面内存数据，刷新后清空。本版本未在真实 TauriTavern 2.4.0 / Windows / Android 设备上做验收。
