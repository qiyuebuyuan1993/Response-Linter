## 自动化回归

使用 Node.js 22.15+（推荐 Node.js 24），无需安装依赖：

```sh
node --test tests/*.mjs
```

若宿主的 Node 测试运行器因沙箱禁止子进程 `spawn`（EPERM），可直接在同一进程执行：

```sh
node tests/regression.mjs
node tests/features-1.4.6.mjs
node tests/features-1.4.7.mjs
node tests/features-1.4.8.mjs
```

## 酒馆内验收

1. 启用扩展，关闭自动修复；对缺少结束标签的最新 AI 消息点击手动修复。
2. 点击撤销，确认显示文本、复制文本和刷新后文本都恢复。
3. 禁用一个必需内容项并保存；关闭再打开编辑器，确认条目仍在且保持关闭。重新启用后检测恢复。
4. 将默认行为改为预览，确认取消不改消息，应用后可撤销。
5. 开启自动修复后重复验证撤销；确认不会因插件自己的渲染事件立即重新修复。
6. 清除所有规则，只开启“清理泄漏的推理块”，点击手动修复预览；确认推理块消失而 `<content>` 正文保留。
7. 在构画设置一个自定义历法，开启“修复 SDC / 正文边界”，构造缺少 SDC-end 的 AI 回复；预览中应使用构画历法推进时间，取消不写入。换聊天后再次修复，历法来源应随新聊天变化。
8. 选择四季 28 日预设，用 `1年冬28日 周日 23:50` 起始、推进 10 分钟，预览应出现 `2年春1日 周一 00:00`。
9. 粘贴非法自定义 JSON，确认提示错误且不覆盖之前有效配置；“检测历法”显示来源和月份。
10. 在流式生成过程中点击手动修复，应提示等待生成完成而不写入。
11. 只开启“修复正文外折叠块顺序与配对”，对已安全的外部区域构造“你的选择是”在“内心独白”之前的回复，预览应只交换两个完整块；取消不写入。只开启“修复 SDC / 正文边界”时，上述折叠块顺序不应改变。
12. 构造 choices 缺少 `</details>`、紧跟完整 monologue 的结构，确认只在明确并列时补一个闭合再交换；末尾有归属不明文字或重复标题时应只警告并保留原文。旧版预设最终顺序是 monologue（内心独白）在前、choices（选项）在后。
13. 打开扩展抽屉和 wand 菜单中的“响应检查器”入口，确认两者打开同一个设置浮层；关闭再打开后，未保存的自定义档案草稿仍在。
14. 新建自定义无时间档案：正文 `【正文】`/`【/正文】`，外部标记 `【水印】`，三个字面结构块顺序自定义；保存后确认正文结束移到外部标记前、目标块按档案顺序重排、中间未知文字逐字节保留。
15. 构造自定义时间模板，例如开始 `【开始：{date}·{weekday}·{time}】`、结束 `【结束：{date}·{weekday}·{time}】`；确认已有结束标记被逐字节移动，缺失时按历法跨年合成。模板会拒绝互相可匹配的含糊起止格式。
16. 使用千千结时，仅开启正文边界/结构块修复并预览，确认消息的 `extra.qianqianjie_floor`、`qqj_v3_recall_receipt`、`qianqianjieAutoHide`、`qianqianjie_memory_excluded`、`swipe_info.extra` 与 `chatMetadata.qianqianjie` 不被改写；撤销仍保留修复后新写入的 QQJ 元数据。不要为本扩展新增 QQJ 存储或迁移。
17. 使用自定义 `<正文>` 等标签时，到千千结/构画的共享正文包装设置中确认相同标签已配置；本扩展不会自动改那边设置。对已记忆的语义正文，优先在提取前修复；已经提取后再改正文，请使用千千结自己的复核/重处理流程。
18. 在 wand/主面板确认 Quick Reply 修复按钮：首次安装可见且只一个；删除按钮后不会被自动重装；点击“手动重试 / 恢复按钮”才重新安装并重新激活自己的组。点击按钮走与手动修复相同的预览/应用路径，不发送消息、不生成回复。斜杠命令冲突时只警告、不覆盖。

自动化测试不能替代真实酒馆版本及其他扩展组合的兼容性验收。撤销历史为页面内存数据，刷新后清空。本版本未在真实 TauriTavern 2.4.0 / Windows / Android 设备上做验收；自动化与仓库内浏览器夹具只覆盖模拟宿主和本次可用视口，不能宣称真机通过。
